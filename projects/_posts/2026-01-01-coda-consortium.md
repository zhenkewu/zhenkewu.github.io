# Overview

The AI-Powered Cause-of-Death Assistant (CODA) Consortium is a Gates Foundation project to improve cause-of-death assignment where medical certification is rare. The consortium is developing AI-enabled tools that can use verbal autopsy and related mortality data to support more reliable cause assignment for public-health surveillance.

**Dates:** 01/2026–09/2027

**Principal Investigator:** [Tyler McCormick](https://thmccormick.github.io) (University of Washington)

**Responsibility:** Principal Investigator on subaward
