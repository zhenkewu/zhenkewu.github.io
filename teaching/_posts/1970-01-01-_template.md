Copy this file to a new `YYYY-MM-DD-short-slug.md` in `teaching/_posts/`, set `published: true` (or delete that line), and replace the fields.

`type` must be one of: `short-course`, `classroom`, `mooc`, `slides`, `reading-group`.

`status` is `upcoming`, `current`, or `past`. Set `year` to this offering so the index sorts it with other activities that year. Optional `priority` (higher first) breaks ties in the same year.

Set `created: true` for a course you developed (not only taught). That prefixes a `†` on the Teaching tab. Set `status: upcoming` to prefix a `*`.

`listing` is the markdown line shown on the Teaching tab. Use `POST_URL` where the link to this post should go.

Links in `canvas`, `syllabus`, `slides`, `code`, `website`, and `materials` become trailing buttons on that index line.

If a course is taught in multiple years and each year needs its own syllabus, Canvas site, or notes, **add one post per offering** and keep the same `course:` value (for example `BIOSTAT653`). The course page will then list the other years under Offerings. Copy last year’s post, change the date/slug/`year`/`term`/`permalink`, and put that year’s material in the body.
